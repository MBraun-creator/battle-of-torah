Export from your original v59 tab

This helper does not access your browser database. No HTML file needs to be edited, moved, or replaced.

  1. Keep your ORIGINAL v59 file open in its original location and Safari profile. Confirm that its Sound Library still shows your sounds.
  2. Click Copy Exporter below. If clipboard access is blocked, click Select Exporter, then press Command-C.
  3. Return to the ORIGINAL v59 tab. Open Develop → Show Web Inspector → Console. Paste with Command-V and press Return once.
  4. A temporary Export panel appears in that original tab. Click Verify Sound Library and confirm the displayed original file address, nonzero sound count, and actual filenames. A newly downloaded HTML file must not be assumed to have access to your original storage.
  5. Only after verifying access, click Export Sound Library, then Download Sound Library Backup. Keep the downloaded JSON backup in two safe places.
  6. You may close the exporter. Refreshing also removes its temporary buttons. Your original file and sound database stay unchanged.

To enable Web Inspector: Safari → Settings → Advanced → Show features for web developers. Then press Option-Command-I in the game tab.
